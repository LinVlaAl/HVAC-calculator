# Инженерия — инженерные калькуляторы ОВИК

Отдельная нейтральная страница: инженерный пакет ОВИК, сборка 2.2 — 25 калькуляторов для
проектной практики ОВиК/ЦОД. Без брендинга, без внешних зависимостей — страница полностью
офлайн: все стили и скрипты внутри одного index.html, шрифт — системный (system-ui).

## Файлы

- `index.html` — вся страница: разметка, стили и JS в одном файле.
- `.nojekyll` — отключает сборку Jekyll на GitHub Pages.

## Публикация на GitHub Pages

1. GitHub → «+» → **New repository** → имя (например, `engineering-calculators`) → **Public** → Create.
2. **uploading an existing file** → загрузить `index.html` и `.nojekyll` → Commit changes.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/(root)** → Save.
4. Через 1–2 минуты сайт доступен по адресу `https://<логин>.github.io/engineering-calculators/`.

## Локальный запуск

Открыть `index.html` в браузере — страница работает офлайн.
На Raspberry Pi/сервере: `python3 -m http.server 8080` в папке с файлом.

## Ограничения GitHub Pages (справочно)

- Только статика: HTML/CSS/JS без серверного кода — эта страница статическая по построению.
- Размер сайта до 1 ГБ, трафик ~100 ГБ/мес (мягкий лимит), публикация с ветки — до 10 сборок в час.
- Сервис не предназначен для e-commerce/SaaS; информационные и инструментальные страницы — допустимы.
